# Notes for contributors
- Deploy only `public/`. Generator and legacy sources live in `tools/`.
- Edit content/layout in `tools/generate_site.py` and CSS/JS in `public/assets/`, then run `python tools/build.py`; hand edits to generated HTML are overwritten.
- No inline `<script>` or `style=` attributes: the CSP (`public/_headers`, `.htaccess`) forbids them. Keep the two header definitions in sync.
- Never crop content photos (`object-fit: cover` only on decorative blurred backdrops). Use lowercase file names.
- `index.html` is the only homepage. The old root `home.html` portal page was removed on purpose: never add it back (the generator refuses to). Header logo, "Home" links, breadcrumbs and footers all point to `index.html`.
- Root pages and sibling institution pages are generated by `tools/generate_portal.py`; shared CSS/JS live in `tools/portal-ui/` and are copied to `public/portal-assets/` (the folder name is historical; every page uses it).
- Tall scroll-reveal lists must keep working on phones: `tools/portal-ui/app.js` reveals items taller than the screen as soon as any part is visible. Run `python3 tools/check_site.py` after every build.
- Phone performance: on screens up to 38rem wide the three background orbs (`.ambient span`, `tools/portal-ui/base.css`) do not animate, because the endless animation of large blurred layers halved the frame rate in tests. Do not re-enable it without measuring on a phone.
- `python3 tools/build.py` now builds everything and then runs the link check; it fails if a link or asset is broken.

- One header for the whole site: `tools/site_header.py` is the only definition (the homepage header). Both generators call it; the Residential School passes `home_href='/'` so its logo and Home item open the root homepage. Never reintroduce a school-specific header or top bar.
- Bayanath videos: `public/Bayanath.html` is generated; cards are drawn by `portal-assets/bayanath.js` from `public/data/bayanath-videos.json`. `tools/update_bayanath.py` (config: `tools/bayanath-config.json`, run by `.github/workflows/update-bayanath.yml` every Friday 21:00 IST = cron `30 15 * * 5` UTC, plus manual start) refreshes that file from the YouTube Data API uploads playlist when the secret `YOUTUBE_API_KEY` exists, otherwise from the channel's public RSS feed, and never overwrites it on failure or when nothing changed. Set `playlist_id` in the config if a verified Bayanath playlist exists; otherwise titles are filtered by `title_keywords`.

## Phase 9 additions
- Page text for the root and institution pages lives in `tools/content_main.py`, `content_more.py` and `content_inst.py` (generated by `generate_portal.py`). Edit there, never the HTML. Add a picture by listing it in `tools/recovery_assets.py` (source, destination, alt text, caption) and re-running `import_recovered_assets.py`; every listed picture must be used on a page or it is an orphan.
- Copied text: when the original repeated one institution's text on another's page, show it once on the institution it describes and add a redirect in `content_inst.REDIRECTS` (the generator asserts that every redirect target and `#id` exists and that no redirect source is still a file).
- Never merge conflicting historical dates or figures silently, and never describe an institution from text that the original attached to another. Label dated fees, strengths and results with the date the source gives.
- Do not publish: named students' certificates, bank details, anything from the server's private area. `tools/phase9_manifest.py` lists what is withheld.
- Shared CSS for recovered content is `tools/portal-ui/recovered.css` (prefix `rc-`); it uses only the existing design tokens, so dark mode follows the theme. `portal.css` is the concatenation of `base.css`, `extras.css` and `recovered.css`.
- Generated routing files: `public/_redirects`, `public/.htaccess` and `public/_headers` are written by `generate_portal.py`; do not edit them by hand.
